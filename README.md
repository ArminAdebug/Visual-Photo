
# Visual Photo Studio

A modern desktop image processing application built with Python and PyQt5, designed for batch image enhancement and artistic transformation.

## Overview

Visual Photo Studio is a user-friendly desktop application that allows users to apply professional visual effects to individual images or entire image collections with just a few clicks. The application features a modern dark-themed interface and supports automated batch processing for efficient workflow management.

Whether you're enhancing personal photos, generating artistic variations, or processing large image datasets, Visual Photo Studio provides a simple and intuitive solution.

## Features

### Modern User Interface

* Dark mode design with purple accent theme
* Clean and intuitive workflow
* Easy effect selection and file management
* Responsive desktop experience powered by PyQt5

### Image Effects

The application currently includes the following image processing effects:

* Oil Painting
* Glow
* Mosaic
* Vintage
* Negative
* Grayscale
* Blur

### Flexible Input Options

* Process a single image file
* Process all images inside a selected directory
* Automatic batch execution
* Preserves original files

## Installation

```bash
git clone https://github.com/ArminAdebug/Visual-Photo.git
cd Visual-Photo
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
